Longhorn Neurotech

A student team building EEG and EMG models small enough to run on a prosthetic's own hardware. I've been a member since my first year:

  • First year, ML Interpretability team: as a team we got our best EEG classifier to 85.71% on its test set
  • Now Edge AI Team Lead, running 10 people split across data processing, the EMG model, the EEG model and quantization with ONNX Runtime
  • We tried several models on a Raspberry Pi Zero 2 W, including XGBoost and a CNN-LSTM, and a small MLP did best
  • That EMG gesture model runs in 0.43 ms per sample instead of 1.04 ms, in 311 KB, at 90.37% accuracy against 90.50% before quantizing

Why I joined

I got into brain-computer interfaces reading about advances like Neuralink's. In my first year I joined the ML Interpretability team, where I built capsule networks for EEG and reordered the channels to match where the electrodes sit on the scalp. That work got me promoted to lead the Edge AI team.

The hard part

Leading ten people who all needed the same hardware. Everyone wanted to test their own model on the Raspberry Pi, so I set up Raspberry Pi Connect and anyone could run inference on it remotely from their own laptop. That let us try several models without passing the board around, and it kept everyone involved. The technical wall was ONNX Runtime: PyTorch's own quantization made the model bigger than the original, so I switched to ONNX Runtime's static quantization, which got it down to 311 KB.
