phy 3D Feature View

A 3D feature view for phy, the open-source tool electrophysiology labs use to sort neural spikes, so clusters can be inspected and split in three dimensions:

  • Plots each cluster's spikes on their first three principal components, for up to 8 clusters and nearby channels within 100 µm
  • Rotate with shift-drag, pan and zoom, and switch between orthographic and perspective views
  • Lasso-select spikes in 3D to split a cluster
  • Submitted upstream as a pull request to phy (cortex-lab/phy #1345), still under review

Why I built it

My work at Longhorn Neurotech made me want to learn more about how neural recordings are analyzed at the level of individual neurons. The lab wanted a 3D view because it lets them compare two clusters across three principal components at once, instead of piecing that together from several 2D plots.

The hard part

The first obstacle was getting phy to run on my Mac. Its older graphics code wouldn't start on Apple Silicon, so I forced an OpenGL 2.1 compatibility profile on macOS and fixed a crash caused by a newer version of joblib. The other difficult part was the lasso split: it only checked the spikes drawn on screen, which are a subsample, so splits were missing spikes. I changed it to reload every spike before splitting.
