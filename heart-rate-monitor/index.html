Cloud to Edge Heart Rate Monitor

A heart-rhythm monitor split between the cloud and a microcontroller:

  • a Raspberry Pi 5 plays the patient, streaming MIT-BIH ECG recordings from Google Cloud Storage to a Pico over USB serial
  • the Pico sorts each heartbeat as normal, supraventricular ectopic or ventricular ectopic with a small neural network I wrote in C, about 115 int8 weights
  • a Python exporter writes the trained weights into a C header, so retraining doesn't mean retyping numbers
  • the Pico's second core is a watchdog that flashes a warning if the data stops for more than a second

Why I built it

I built it on my own to experiment with how edge devices and the cloud can work together. I pictured it as a small, independent backup that double-checks the readings from a clinic's heart monitor.

The hard part

Getting the Pico's two cores to work together. Core 0 reads the stream and runs the network, and stamps a shared timestamp every time a sample arrives. Core 1 waits for that first sample, then watches the timestamp and panics if it goes more than a second without changing. Both cores drive the same LED, so the results had to stay readable next to the alarm: one to three blinks for the beat type, a fast 30 ms strobe for a panic.
