Cloud to Edge Heart Rate Monitor

A heart-rhythm monitor split between the cloud and a microcontroller:

  • A Raspberry Pi 5 plays the patient, streaming MIT-BIH ECG recordings from Google Cloud Storage to a Pico over USB serial
  • The Pico classifies each heartbeat as normal, supraventricular ectopic or ventricular ectopic using a small neural network I wrote in C (about 115 int8 weights)
  • A Python exporter writes the trained weights into a C header, so retrained weights go straight into the firmware
  • The Pico's second core is a watchdog that flashes a warning if the data stops for more than a second

Why I built it

I built this on my own to explore how edge devices and the cloud can work together. I designed it as a small, independent backup that could double-check the readings from a clinic's heart monitor.

The hard part

The hardest part was coordinating the Pico's two cores. Core 0 reads the incoming stream, runs the network and updates a shared timestamp with every sample. Core 1 waits for the first sample, then monitors that timestamp and raises an alarm if it stops updating for more than a second. Both cores share one LED, so the output had to stay distinguishable from the alarm: one to three blinks for the beat type, and a fast 30 ms strobe for a fault.
