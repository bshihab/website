Embedded Multiplayer Racer

A two-player racing game inspired by classic Mario Kart, written in bare-metal C on a TI microcontroller for ECE 319K:

  • Two boards, one per player, keep the same race in sync over UART
  • Power-ups like bananas and bombs, joystick input through the ADC and sound through the DAC, all running in a 30 Hz game loop
  • I wrote the physics and controls, including the movement and bouncing; my partner wrote the UART protocol, the interrupts for the power-ups and the illustrations
  • Voted Best Game in the class competition, Fall 2025

Why we built it

We wanted to build a two-player racing game inspired by classic Mario Kart.

The hard part

Two-player mode was the hardest part. We knew it would be difficult, but it made the game far more fun. Both boards have to agree on a single race: each sends its car's position and angle over UART, along with events like a dropped banana, and the other board applies them within the same 30 Hz loop that reads the joystick and updates the screen.
